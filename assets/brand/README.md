# EluShell 应用图标

ES 分别取自 Elu 与 Shell，字母 E 内嵌终端提示符 `>_`。深海军蓝底色、青绿色 E 和白色 S 用于桌面、任务栏、安装程序与操作指南。

原始资产 `elushell-icon.png` 保留透明通道。`build/icon.ico` 包含 16、24、32、48、64、128、256 像素尺寸；`build/icon.png` 为窗口图标。通过内置 image_gen 工具生成，未使用 CLI/API 回退。导出仅进行缩放与格式转换。
