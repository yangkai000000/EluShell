## 目录同步设计

真实连接建立时，在当前交互 Shell 执行一次仅存在于当前会话的 `printf` 身份探测，输出带随机会话标识的 OSC 控制序列以获取 Shell PID。活动会话每秒通过独立 exec 通道读取 `/proc/<pid>/cwd`，仅在目录变化时刷新 SFTP 列表，避免从屏幕提示符或 `cd` 字符串猜路径。目录树自动展开选中路径的祖先；手工浏览不会在 Shell cwd 未改变时被反复拉回。

不修改 `.bashrc`、`.zshrc` 或服务器文件。不安装驻留代理。该机制面向 Linux 上支持 `$$` 的 Shell；进入嵌套 Shell、tmux 内部窗口或不提供 `/proc` 的系统时，不保证跟随嵌套会话的目录。演示模式提供对应的交互模拟，并非真实协议测试的替代。

## 隧道设计

- 本地转发：客户端监听 `bindHost:bindPort`，经 SSH `direct-tcpip` 转发到服务器可访问的目标。
- 远程转发：SSH 服务端监听请求的地址端口，收到 `forwarded-tcpip` 后由桌面端连接本机可达的目标。
- 默认监听 `127.0.0.1`；远程实际监听范围受服务器 `GatewayPorts`、`AllowTcpForwarding` 等配置约束。
- 任何规则建立失败会关闭已建立的规则并断开该次连接；监听端口冲突明确报错。关闭会话释放监听器及转发连接。
- 本轮未实现 SOCKS 动态转发、跳板机、HTTP/SOCKS 代理与隧道热修改。已连接会话编辑规则后需重新连接才生效。

## 操作

拖动监控栏右边、终端下边、目录树右边的分隔线即可调整尺寸。分隔线可用方向键微调，双击可折叠。终端工具栏按钮恢复监控/文件面板，「终端专注模式」一起收起或恢复。文件工具栏可单独隐藏目录树。

文件区保留路径输入、刷新、筛选、上传和下载。选择目录树节点会更新内容列表，点击列表中的文件夹会同步目录树；勾选「跟随终端」后，终端改变 cwd 会同步文件区。
