# EluShell 0.9.1 Mac 上传诊断版

发布日期：2026-09-14。此版本用于定位上传时出现的 Permission denied，保留原有上传策略。

1. 下载与你的芯片一致的包：Apple M 系列选 arm64，Intel 选 x64。
2. 按 Command+Q 完全退出 EluShell，用新版替换“应用程序”中的 EluShell.app。保留 ~/.EluShell，其中是原有连接和个人设置。
3. 启动后，在工作区设置 → 更新配置确认版本号为 0.9.1。
4. 使用发生问题的连接，进入相同的远程目录，再上传一次原来的文件。
5. 出现报错后，在“文件传输”面板点击“导出诊断日志”，保存生成的 EluShell-0.9.1-diagnostics-时间.jsonl 文件并回传给开发人员。
6. 回传时附上：Mac 芯片与系统版本；通过拖拽还是上传按钮操作；是否覆盖同名文件；Windows 成功上传时的客户端版本、登录账号与目标目录。

日志包括软件版本、系统与架构、服务器地址、登录账号、文件路径、文件大小与权限，以及本地读取和各阶段 SFTP 操作的错误码。日志不采集密码、私钥、文件内容或终端内容。请回传导出的 JSONL 文件，不需要导出连接配置。

原始日志位于 ~/.EluShell/logs/transfers.jsonl，自动轮换保留最近三份，每份约 2 MiB。重启后仍可导出最近日志。若上传成功，也请导出一次日志便于对比。

此 Mac 测试包沿用 ad-hoc 签名，未做 Apple Developer ID 签名或公证。已验证的范围是自动化 SSH/SFTP 测试、Windows 上运行 Mac 应用载荷、包结构与离线签名检查；不等同于 Mac 真机验收。
