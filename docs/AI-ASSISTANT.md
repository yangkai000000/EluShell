# AI 命令助手（0.8.2）

会话栏右侧的星光图标展开 AI 对话。拖动左边界调整宽度，双击分隔线或点击关闭图标收起。SSH 会话和对话独立，可以先咨询再连接服务器。

## 配置

打开工作区设置中的「AI 命令助手」，选择 DeepSeek 或 Kimi，填写该平台的 API Key，点击「保存 AI 配置」。接口、模型和输出上限已预填。两家的 Key 分开保存；默认供应商决定新对话使用哪个接口。

| 模型 | 思考选项 | 预设基础地址 |
| --- | --- | --- |
| DeepSeek V4 Flash / Pro | 关闭、轻量、深入、最高 | `https://api.deepseek.com` |
| Kimi K3 | 轻量、深入、最高 | `https://api.moonshot.cn/v1` |
| Kimi K2.6 | 关闭、深入 | 同上 |
| Kimi K2.7 Code / Highspeed | 深入（始终思考） | 同上 |

高级配置可以调整 OpenAI 兼容 HTTPS 基础地址、单次输出上限（含思考）。不要填写 `/anthropic` 或完整 `/chat/completions` 路径。更换地址后需重新保存 Key，避免旧 Key 被发往新地址。已有对话保留创建时的模型、地址、思考强度和输出上限，修改后新建对话生效。

参数核对日期：2026-09-10。依据 [DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[DeepSeek 模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[Kimi 快速开始](https://platform.kimi.com/docs/get-api-key)、[Kimi 参数参考](https://platform.kimi.com/docs/api/models-overview)。Kimi K3 / K2.7 多轮请求保留 API 返回的思考上下文；连接服务器后，应用发送受限的只读工具定义。

## 自定义接口

选择「自定义」，填写服务商的 HTTPS API 基础地址（例如 `https://api.example.com/v1`）、API Key 和模型 ID。使用 OpenAI 兼容 Chat Completions 流式接口；网站首页不是 API 地址，地址中不含 `/chat/completions`。将新对话默认供应商设为「自定义」，保存后新建对话。

默认不发送思考参数。模型支持 `reasoning_effort` 时，可选择轻量、标准或深入。高级配置允许调整上下文容量（默认 128000 tokens）、输出上限及 `max_tokens` / `max_completion_tokens` 参数。各服务商支持范围不同，按其文档选择；上下文是估算。请求格式参考 [OpenAI 官方 Chat Completions 类型定义](https://github.com/openai/openai-python/blob/main/src/openai/types/chat/completion_create_params.py)。

已保存的 API Key 显示固定数量黑点，不透露原值或长度。不修改输入框则保留原 Key；输入新 Key 后保存可替换。「移除已保存的 Key」后保存可清除。接口地址改变时不会沿用旧 Key，已有对话保留原接口，需要新建对话使用新配置。

## 使用

- Enter 发送、Shift+Enter 换行。回答逐步显示，思考内容可折叠；「停止」中止生成，「重新回答」重试最后一轮。
- 连接服务器后可以直接问「查一下 nginx 在什么目录」「查看 itos.conf 中的配置」。AI 使用只读工具列目录、查找路径、读取文件或搜索文本，再依据实际结果回答；每次查询结果可以展开查看。
- 终端选择文字后，在浮动菜单或右键菜单点击「发送给 AI」。内容显示在输入框上方的「N行选中内容」中，与输入的问题分开，可展开或移除。
- 右键文件或文件夹选择「标记给 AI」，支持多选。路径以独立引用显示，AI 优先在这些位置查找和读取。引用保留来源服务器，切换到其他服务器后需移除引用或切回来源服务器再发送。
- 在输入框粘贴剪贴板图片。没有本地文件选择入口，文件与文件夹仅通过服务器菜单标记。支持 PNG、JPEG、WebP，每张最多 5 MB，每轮最多 4 张，总附件最多 12 项。图片会预览并保存到历史；所选接口和模型需支持视觉输入。
- AI 没有直接修改文件或服务器状态的能力。只读工具由主进程限制，无任意 shell 执行、写入、删除、权限修改或重启工具。AI 代码块仅提供复制，不再提供填入或执行按钮。
- 只读文件限制为普通文本文件、最多 2 MB，单次返回最多 60000 字符；目录列表最多 500 项，路径查找深度最多 16 层。超限、断连和权限错误会显示在工具结果中。每轮最多 24 次查询，支持停止。
- 未连接时仍可聊天和分析图片。接口收到对话、主动附加的引用和图片，以及 AI 实际查询的内容；不会自动上传整个终端或连接密码。

## 历史和上下文

「＋」新建对话，时钟图标查看历史，可搜索、重命名、删除。最多保留 100 个对话，纵向滚动；达到上限时提示整理，不自动删除旧记录。每个对话最多 200 条消息，单次提问最多 20,000 字符。

底部显示上下文剩余估算并预留输出空间。估算与供应商实际分词可能不同；API 返回 usage 时，另显示上次实际输入、输出 token 数。上下文不足时提示新建对话，不静默丢弃旧消息。中断和接口错误保留在历史中，可以重试。

## 存储及验证

`%USERPROFILE%/.EluShell/ai-settings.json` 保存配置和系统加密的 API Key；`ai-chats/<对话 ID>.json` 保存本地明文对话、引用、图片及只读查询结果。连接导出不包含 AI Key 和对话。

本版本用隔离 HTTP/SSE 和 SSH/SFTP 测试服务验证参数、流式工具循环、取消、保存和错误处理。没有用户的真实供应商 Key，未发起付费 API 请求；安装后填写自己的 Key 验证账户权限和额度。
