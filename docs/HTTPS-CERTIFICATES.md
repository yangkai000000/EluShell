# 内网 HTTPS 证书工具

需要在服务器上独立运行时，可使用 [`scripts/elushell-https.sh`](../scripts/elushell-https.sh)，交互及参数用法见[独立脚本说明](HTTPS-SCRIPT.md)。

入口：连接服务器后，打开底部「工具包」，双击「HTTPS 证书」。工具在工作区新标签页打开，并使用该连接的 SSH 认证信息。

缺少 HTTP SSL 模块时，工具会在生成前停止，不修改站点。可点击「检查 / 升级 Nginx 的 SSL 支持」进入[离线升级工具](NGINX-UPGRADE.md)，升级成功后再继续配置证书。

1. 填写服务器上包含 HTTP `server` 块的 Nginx 配置文件，点击「读取配置」。如有多个站点，选择本次要配置的站点。
2. 填写用户实际访问的 IP 和内网域名，一行一个。支持 IPv4、IPv6 和 DNS 名称，地址写入证书 SAN；不要填写 `https://`、端口或 URL 路径。
3. 设置有效期和 HTTPS 端口，分别指定「证书存放目录」与「KEY 存放目录」，两者可相同。目录不存在时会创建；每次生成独立名称的 `.crt` 和 `.key`，不覆盖已有文件。
4. 默认勾选「生成后写入所选站点配置并重载 Nginx」。填写实际运行实例使用的主配置文件与 Nginx 程序路径；站点文件必须被该主配置加载。只需文件时，可以取消勾选。
5. 点击「预览生成结果」，核对适用地址、输出路径、配置备份路径及修改前后内容，再点击生成按钮。

证书为 RSA 2048 / SHA-256 自签名服务器证书，不连接外部证书颁发机构，也不需要域名验证。浏览器默认不信任自签名证书；可从文件管理下载 `.crt`，按客户端系统的信任管理流程导入。私钥留在服务器，文件权限为 `600`，不要分发给客户端。到期前需重新生成并应用，此工具不安装自动续期任务。

工具只修改所选 HTTP 站点的证书路径，保留原有 HTTP 入口；新站点增加指定 HTTPS 监听，已有 HTTPS 站点使用原有端口。已有多套证书的复杂站点需要先手动整理。应用前后执行 Nginx 配置检查，通过后发送重载命令。原配置备份位于原文件同目录的隐藏 `.bak` 文件中，具体路径显示在预览和日志里。

配置自读取后发生变化时会拒绝应用；校验或重载命令失败时尝试恢复原配置。若应用期间其他管理员再次修改配置，则保留其改动和生成的证书，并显示备份位置，交由管理员核对。

目标服务器需有 Linux 常用工具、OpenSSL 和 Nginx。当前 SSH 用户需能读取配置、写入目标目录、备份替换配置及重载 Nginx；可显式勾选免密 `sudo`。任务不使用终端中临时切换的 `su` 身份，也不安装系统依赖。任务执行期间保持连接，工具会阻止关闭连接、退出和安装更新。操作日志报告配置检查和重载命令结果，不代表已验证防火墙放行或客户端可访问。
