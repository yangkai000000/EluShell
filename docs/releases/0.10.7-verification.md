# 0.10.7 — Separate HTTP entrance for HTTPS redirection

The redirect checkbox was disabled for HTTPS-only business server blocks. It now remains usable and offers an HTTP entrance selector for plain HTTP blocks in the same file. A unique identical `server_name` set is suggested; ambiguous or unrelated names require explicit selection. Reinspection prefers the matching existing HTTPS business block, preventing accidental addition of another TLS listener to its HTTP counterpart.

Certificate directives remain in the chosen HTTPS block. The scheme-guarded 308 rule is placed in the selected HTTP block. Existing manual redirects are reported and preserved; disabling the tool rule restores their precedence. Preview identifies the affected HTTP entrance and retained manual redirect. Other files and other HTTPS business blocks are not rewritten.
