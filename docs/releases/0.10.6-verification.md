# 0.10.6 — HTTPS redirect option

Added an optional HTTP → HTTPS 308 redirect to the selected business server block. It is disabled by default, uses the configured TLS port, preserves the requested host and URI, and is guarded by `$scheme = http`. Reinspection restores the tool-managed setting. Reapplication is idempotent; disabling removes only an intact EluShell-managed rule. User-authored redirects are retained, and standalone redirect entries cannot be selected as business sites.
