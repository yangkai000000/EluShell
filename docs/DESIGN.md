# 页面与交互

## 工作区布局

- 顶部：终端正上方的会话栏；左侧连接管理图标，右侧布局、传输和设置。满行换行。
- 启动与「＋」：新标签页的紧凑最近连接表，双击连接，原会话持续保留。
- 最近连接表靠上放置，移除内部重复标题和连接管理入口。100 条记录采用固定表头的内滚动列表，避免分页切换；搜索覆盖全部记录。命令分类单行横向滚动，命令列表独立纵向滚动，防止小面板中多行分类挤占内容。
- 左侧：连接身份与运行时间，然后依次为 CPU、内存、网络、活跃进程、磁盘与 I/O。常用的进程管理入口放在磁盘信息之前，每块可进入详情。
- 中间：服务器会话标签、连接标题、深色终端、命令输入栏、文件/命令/历史工作区。
- 0.2.0 移除右侧快捷命令栏，命令保留在底部标签。终端占据剩余主要空间；底部文件区左侧为目录树，右侧为选中目录内容。
- 底部：连接状态、编码、终端类型、监控间隔与最近更新时间。

颜色使用低饱和灰蓝和青绿；终端采用深色，与图表和文件列表区分。保留开发工具的信息密度，避免把终端变成大面积仪表盘。CPU 用折线和核心条块，内存用环形，容量用条形，网络用速率与折线。

## 关键交互

共享命令库以分类文件夹加名称列表展示，单击直接发送到当前终端，末尾是否回车按命令配置。右键编辑、复制、删除或移动分类。右侧编辑器支持当前/全部会话发送。输入栏模糊匹配当前连接历史和共享命令，Tab 填入，没有匹配时尝试 SFTP 路径。直接聚焦终端后仍由远程 Shell 提供完整交互与补全。

连接管理使用左列表右表单。搜索同时匹配名称、主机和分组。用户可仅保存或保存并连接。登录命令与自动执行开关按服务器保存；密码可用系统加密本地保存。

监控栏宽度、文件区高度、目录树宽度可拖拽调整，双击分隔线折叠，工具栏按钮恢复。尺寸和折叠状态记忆在本机。文件区「跟随终端」开关决定是否跟随实际 Shell cwd；选中节点自动展开祖先并滚动到可见位置。新建连接表单增加多条本地/远程转发规则。

内存详情显示可用/缓存/交换，而非只显示一个百分比。网络详情显示每接口速率、累计字节、路由和连接。磁盘详情同时列出挂载目录容量与设备 I/O，明确目录容量和设备读写不是同一口径。

没有演示模式。没有桌面桥接的网页版本会提示真实 SSH 需要桌面程序。

## 0.3.0 紧凑会话栏与文件编辑

界面顶部只保留一行会话标签：左侧连接管理图标，右侧传输与设置图标。原品牌顶栏、最左独立导航列移除；连接信息压缩为终端上方一条细行。原有分隔线、折叠和目录跟随交互保持可用。

文件树节点和文件列表支持右键菜单，空白区域以当前目录为目标；文件夹单击导航，文件双击打开内置编辑器。危险操作展示具体目标路径并由主进程确认删除。权限输入使用八进制，目录可勾选递归应用。

传输面板从会话栏展开，显示下载路径、字节数、文件数、状态、取消和定位结果。下载重名自动编号；上传同名文件确认覆盖。编辑器近全屏展示代码、行号、语法高亮、UTF-8/LF/CRLF 和同步状态；Ctrl+F 查找/替换，Ctrl+S 保存，修改后标题带圆点。发生远端冲突时保留用户输入并展示错误，关闭时可继续编辑或明确放弃。
