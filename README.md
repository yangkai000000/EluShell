# EluShell

面向开发者的 SSH 桌面工作台。保留 FinalShell 的「左侧服务器指标 + 多会话终端 + 底部文件/命令」布局，以浅色工作区和深色终端提升信息层次。

## 已实现

- SSH 多会话、PTY、终端尺寸同步、输出搜索、断线状态与重新连接入口。
- 密码、私钥（可带口令）、SSH Agent / Windows Pageant 认证；首次连接核对指纹，指纹变化时阻止连接。
- 服务器名称、分组、搜索、标签、独立登录命令；自动执行默认关闭，开启后每次连接执行。
- 总 CPU、各逻辑核心、1/5/15 分钟负载、运行时间；CPU 趋势。
- 内存环形图、可用内存、页缓存与交换空间详情。
- 各网络接口速率与累计流量、接收速率趋势、路由与 TCP/UDP 连接详情。
- 挂载目录容量、设备读写速率、IOPS、忙碌率与原始计数。
- 进程管理列表支持每列排序、筛选、复制字段和终止，位置优先显示服务 JAR/DLL/脚本。
- SFTP 目录树和文件列表，支持文件夹上传下载、权限勾选、目录右键 cd、双击文件打开内置文本编辑器。
- 共享命令库内置 Linux、Java、Docker、Nginx、Kubernetes 等命令，支持文件夹分类、紧凑名称列表和右键管理。
- 输入栏命令补全、SFTP 路径补全、每服务器最近 100 条历史；Tab、上下箭头、Esc、Enter 操作。
- 监控间隔设置，配置原子写入，本地持久化；仅轮询活动会话。

## 使用流程

1. 「连接管理」→右键文件夹或「连接 / 未分类」→「添加 SSH 服务器」，填写名称、主机、端口与认证信息。
2. 按文件夹整理服务器；共享命令库的内置命令在「默认分类」，可另建分类保存项目命令。
3. 按需填写登录命令，如 `cd /opt/services`。勾选自动执行后才会在连接时发送。
4. 「保存并连接」，核对服务器 SSH 公钥指纹。
5. 左侧点击 CPU、内存、网络、磁盘、进程查看详情。底部目录栏可直接输入远程路径并回车。
6. 单击命令库名称直接发送到当前终端，是否末尾回车由该命令设置决定。右侧编辑器可发送到当前或全部已连接会话，支持 Ctrl+Enter、发送后清空、回车和字体设置。
7. 终端下方输入栏实时模糊匹配当前连接的历史与共享命令，↑↓ 选择、Tab 填入、Enter 发送；历史按钮查看当前连接最近 100 条。直接聚焦终端仍使用 Shell 原生交互与补全。

连接编辑默认勾选加密保存密码/私钥口令，Windows 下通过系统 DPAPI 加密保存；取消勾选并保存可清除。配置会保存私钥文件路径，不复制私钥内容。输入栏历史会保存命令文本，可在「执行历史」中清空。

## 当前边界

当前版本为 0.8.1；使用 Windows x64 本地 SSH/SFTP 服务验证，并通过授权的真实 Linux 服务器验证无回显登录、目录同步及用户/用户组读取。其他 Linux 发行版仍需进一步验收。监控依赖 Linux `/proc`、`df` 和 `ps`，`ip`/`ss` 缺失时降级显示。

尚未包含 RDP、跳板机/代理、SOCKS 动态转发、断点续传。本地/远程端口转发已实现，服务器需允许 SSH 转发。目录同步跟随初始 Linux Shell，暂不跟随嵌套 Shell/tmux 窗口。路径输入栏补全针对不带空格的末尾路径片段；复杂 Shell 语法与带空格路径可在终端使用远端 Shell 的原生补全。指标历史是当前进程内的最近 40 个采样点，未做长期存储。

发行产物未配置代码签名证书，使用 EluShell ES 终端图标；当前仅验证 Windows 平台，不宣称已验证 macOS/Linux 安装包。

## 0.3.0 文件工作区

- 移除品牌顶栏与最左图标栏。会话行左侧是连接管理，右侧是传输进度与设置。
- 在文件列表或目录树右键，可上传文件/文件夹、递归下载、新建、重命名、修改权限及删除。删除前有确认；文件夹上传合并目录，覆盖同名文件前有确认。
- 下载默认使用系统实际桌面的 `esdownload` 文件夹，支持 OneDrive 桌面。点击会话行右侧的传输图标可更改目录、打开目录、查看字节和文件进度、取消任务、定位下载文件。同名下载自动改名。
- 双击文件打开自带 CodeMirror 文本编辑器；支持语法高亮、撤销、查找替换，Ctrl+S 上传保存。关闭未保存文档时可保存、放弃或继续编辑。
- 编辑器支持 4 MiB 以内 UTF-8 文本并保留 LF/CRLF；二进制与其他编码可直接下载。打开和保存也计入传输任务，编辑缓冲在内存中，不自动留下本地文本副本。
- 保存先检查远端内容是否改变，再写入同目录临时文件后替换；冲突时拒绝覆盖。此检查不是跨客户端文件锁。保留文件权限，但替换文件的所有者为当前 SSH 用户。
- 递归上传/下载与权限修改不跟随符号链接，遇到时明确报错；递归删除只删除链接本身。目录最多 64 层、20000 项。取消或失败的目录传输可能留下已经完成的部分内容；暂不支持断点续传。

`npm run test:files` 通过独立本地 SSH/SFTP 服务验证上述桌面操作；加 `-- --packaged` 验证打包程序。

## 0.4.0 本地配置、连接分类与进程管理

配置根目录为 `%USERPROFILE%/.EluShell`，可在「工作区设置」打开。首次使用新版时，将旧 AppData 用户数据目录中的 settings.json、known-hosts.json 和 downloads.json 复制迁移，已有新目录配置不覆盖，旧文件保留。

- `settings.json`：连接、文件夹树、隧道、命令与历史。旧版分组迁移为根级文件夹。
- `credentials.json`：系统加密的密码/私钥口令，绑定主机、端口、用户名和认证方式。密码不会回填到界面；留空使用已保存密码。换主机或用户后需重新输入。旧版没有保存过的密码需输入一次。
- `downloads.json` / `exports.json`：下载和连接导出目录。默认下载到系统桌面 esdownload，默认导出到 .EluShell/exports。导出包含连接、分类、隧道与登录命令，默认附带已保存的密码，也可取消勾选密码。
- 连接管理支持多级文件夹、新建、右键改名、拖动调整层级，以及更改连接的所属文件夹。连接编辑使用「SSH 连接 / 登录命令 / 隧道」三个页签；隧道支持本地 -L 与远程 -R。
- 点击左侧「活跃进程」打开全进程表，PID、用户、内存、CPU、状态、名称、命令行和位置均可正序/倒序排列。支持筛选、刷新、右键复制任一字段、确认后发送 SIGTERM。
- 终止操作检查 PID 与内核启动时间，拒绝 PID 1 和当前终端 Shell。按当前 SSH 用户权限执行，不自动 sudo；部分进程的可执行位置可能无权限读取，CPU 是 ps 的生命周期平均值。进程面板通过刷新按钮更新。

0.4.0 验证：29 项单元/协议测试、连接管理与文件操作桌面测试、打包回归；用户授权 Linux 主机只读查询返回 343 个进程，启动时间身份检查通过。未在真实服务器上终止任何进程。

## 0.4.1 进程服务位置与内存单位

进程表「位置」优先显示 Java 的实际 JAR、dotnet 的 DLL、Node/Python/Shell 的启动脚本。Java 支持 JVM 参数出现在 -jar 前或后的启动写法，不将 Java Agent 和 java.library.path 当作服务文件。相对启动路径结合 /proc/PID/cwd 解析，参数从 /proc/PID/cmdline 的 NUL 分隔数据读取，保留路径中的空格。

详情区分别显示服务位置、工作目录和运行程序（JDK/java、dotnet 等），并标注位置来源。无法确定脚本/模块入口时回退至工作目录；无权限读取时显示未识别，不编造绝对路径。右键可复制位置、工作目录或运行程序。

内存按 1024 进位自动显示 GB / MB / KB / B，保留一位小数（B 为整数），例如 4023.6 MB 显示 3.9 GB。列排序使用原始字节数，悬停显示精确字节数。


## 0.5.0 紧凑布局、外观与分类交互

- 概览栏从内容顶部开始，与终端间距缩至 4 px。会话栏放在终端正上方，满行后自动换行。移除连接摘要和终端工具栏；面板折叠、专注模式及连接设置可从会话栏的布局图标打开，也可双击会话标签编辑连接。
- 终端右上角浮动搜索，Ctrl+Shift+F 打开，Enter / Shift+Enter 查找下一项/上一项，Esc 关闭并回到终端。
- 工作区设置支持界面字体/字号、终端字体/字号，实时应用并自动保存。支持输入本机字体名称，未安装字体由系统回退。
- 工作区与终端背景支持六位十六进制色号、调色板、屏幕取色及 PNG/JPG/WebP 本地图片。勾选包含终端时共用背景，否则分别设置；切换不会清除独立终端配置。图片居中铺满，终端图片加暗色遮罩确保文字可读。
- 选中的图片转为 PNG 副本保存在 .EluShell/backgrounds，settings.json 只保存资源标识和外观选项。原图片移动后不影响使用。输入限 20 MB / 4000 万像素；恢复默认外观不删除已导入文件。
- 单击分类显示路径、直属子文件夹和连接数及内容。右键文件夹新建子文件夹、改名、添加 SSH 服务器，移除顶部 SSH 添加按钮与删除空文件夹操作。拖动可移动整个目录树或连接，也能放回根目录；拒绝拖到自身或子目录。
- 左侧连接和右侧文件夹内容内的连接均可双击直接登录，成功后关闭管理窗口；未保存密码时保留编辑页提示输入，连接失败时显示原因。
- 配置原子替换增加 Windows 短暂文件占用重试，保留旧文件直到新内容替换成功。

验证新增功能：`npm run test:appearance`；验证发行目录：`npm run test:appearance -- --packaged`。完整的本地构建可用 `npm run dist -- --config.electronDist=node_modules/electron/dist`，无需重复下载 Electron。

## 0.6.0 命令工作区与快速连接

- 命令库只显示单行名称，全部连接共用分类和命令。旧服务器专属命令自动迁入默认分类，内置命令只初始化一次，删除后不会重启恢复。右键支持新增、编辑、复制、删除、移动分类，命令也可拖到分类。
- 右侧命令编辑器支持多行文本、缩放/折叠、字号、换行、Ctrl+Enter、末尾 CR、发送后清空，发送目标为当前或全部已连接会话。草稿和这些选项均保存于 `.EluShell/settings.json`。
- 通过输入栏、命令库、编辑器和目录 cd 发送的命令，按连接 ID 去重保留最近 100 条；多个标签连接同一配置时共用该连接历史。仅记录发送成功的会话。终端直接按键不做逐键日志记录。
- 权限弹窗提供所有者、用户组、其他用户的读/写/执行勾选，与三位/四位八进制值双向同步，保留特殊权限位。目录仍可递归应用到全部子项。
- 文件列表和目录树右键「执行 cd 到该目录」发送经过 Shell 引号处理的命令；「跟随终端」开启时文件区继续跟随实际 Shell 目录。
- 启动和「＋」创建新标签页；最近连接按成功连接时间去重保存，最多 100 项，可筛选或清空记录。单击选择，双击或 Enter 连接，缺少密码时打开对应连接表单。切换新标签页保留已有终端与输出。

验证：`npm run test:commands`、`npm run test:newtab`、`npm run test:files`；加 `-- --packaged` 对打包程序运行。

## 0.6.1 列表布局与极限场景

- 去掉新标签页内部的标题、说明和重复连接管理按钮。最近连接列表位于会话栏下方 16–48 px，随窗口大小调整，条目少时也不会垂直居中。
- 最近连接保留 100 条，不分页、不截断为前几条。列表内滚动、固定表头、数量提示、全列表搜索，支持上下方向键及 Home/End 定位；连接第 101 台服务器时移除最旧的最近记录，原保存配置仍保留。
- 命令分类固定单行，分类较多时横向滚动，鼠标滚轮也可横向浏览。命令列表独立纵向滚动，滚动区域显示滑块并阻止滚轮传到外层；切换分类或搜索时回到顶部。长分类名保留开头并显示省略号，悬停查看完整名称。
- `npm run test:stress` 使用隔离本地数据验证 100 最近连接、1000 保存连接、1000 命令、1000 分类、100 历史、8000 字符/400 行编辑器、1000 文件、1000 进程、30 标签及 1060×700 小窗口；包含真实鼠标滚轮和滑块拖动，非仅修改 DOM 滚动位置。

## 0.6.2 启动与概览顺序

- 「活跃进程」移至「磁盘与 I/O」上方，保留点击打开进程管理。
- 增加可选择安装目录的 Windows 安装包。安装后直接运行应用，避免便携包每次解压。卸载保留用户配置。
- 终端及搜索组件在连接服务器时加载；新标签页不预加载 xterm。已有配置通过校验且无需迁移时，不在启动时重复写盘。
- 本机各三次连续启动计时：旧便携版平均 10.34 秒；新安装版首次 2.36 秒，随后 0.55 / 0.57 秒，平均 1.16 秒。计时包含启动进程到新标签页可用及自动化检查开销，不是操作系统冷启动或其他机器的性能保证。详见 `test-results/startup-installed-after.json`。
